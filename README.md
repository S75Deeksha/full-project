# Smart Campus Management System (SCM Project)

## Backend Module – Group Project

A browser-based **Smart Campus Management System** developed as a collaborative Software Configuration Management (SCM) project. The application is divided into three major modules developed by three team members. This repository/documentation describes **my contribution**, which focuses on the **Backend Module**.

---

## Project Status

**Version:** 1.0

---

## Team Structure

This is a **group project consisting of three members**.

The project is divided into the following modules:

* **Frontend Module** – User Interface (HTML, CSS, JavaScript)
* **Backend Module** – Business Logic (Python) **← My Contribution**
* **Database / Data Module** – Data Storage and Management

Each team member is responsible for developing one module with individual Git commits, after which all modules are integrated into one complete Smart Campus Management System.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/S75Deeksha/full-project.git
cd full-project
```

### Run the Backend

Run the required Python module:

```bash
python login.py
```

or

```bash
python food.py
```

or

```bash
python attendance.py
```

or

```bash
python library.py
```
